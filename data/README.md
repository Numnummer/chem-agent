## Формат корпуса для `map`

CSV с колонками `id` и `rxn_smiles` (имена меняются флагами `--id-col` и
`--smiles-col`) и необязательной `source` (патент; флаг `--source-col`).
Реакция записывается как `A.B>агенты>P` или `A.B>>P`. Уже размеченные
реакции (с `:номерами` атомов) принимаются как есть.

Выгрузку `raw/all_balanced_reactions_training.csv` к этому формату
приводит `make corpus` (решение 0008): результат — `outputs/<дата>-full-v1/`
(`corpus.csv` для `map`, `meta.csv` с патентами, условиями и уравненными
реакциями, `prep_report.md`). Только выборки без NaOH:
`make corpus LABEL=core-v1 PREP_ARGS="--exclude-subset NAOH 2naoh"`.

Особенности выгрузки: 97% — NaOH-реакции; выборка «сера» собрана по `S`
(сероводород), элементарная сера — в 225 реакциях; у 40 411 записей
(`2naoh_dataset`) нет патента — в выдаче они помечаются «без источника».

## Список покупаемых (`--purchasable`)

CSV с колонкой `smiles`. Для реального прогона его выгружают из базы
экономического агента (5422 вещества с офферами).
