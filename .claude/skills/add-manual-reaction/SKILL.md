Добавь в ручную библиотеку реакцию: $ARGUMENTS

1. Запиши реакцию в SMILES: `реагенты>>основной продукт`. Побочные продукты
   (вода, соли) не пиши — их достраивает балансировщик. Сверься с правилами
   из скилла `chem-conventions` (S8, NaOH, заряды).
2. Проверь в RDKit, что все SMILES парсятся, и выведи брутто-формулы реагентов
   и продукта: атомы продукта должны браться из реагентов.
3. Источник обязателен: процесс, учебник, справочник или патент. Без источника
   не добавляй — спроси пользователя.
4. Добавь строку `id,rxn_smiles,source,note`. Префикс id задаёт класс:
   `MAN-S` — сера, `MAN-C` — углерод/CO2, `MAN-N` — азот, `MAN-E` — электрохимия,
   `MAN-O` — прочее.
5. `make fixtures`, затем `make test`. Все шаблоны должны пройти самопроверку
   (`test_all_templates_reproduce_their_precedents`).
6. Если реакция открывает новый маршрут из перечня ТЗ, добавь тест в
   `tests/test_template_engine.py` по образцу `test_sles_route_found_from_priority_set`.
7. Покажи диф и результат тестов.

Если маппинг разметил реакцию неверно (самопроверка не прошла), не подгоняй
SMILES — сообщи об этом: такие реакции нужно вносить готовым шаблоном, и это
отдельная задача.
