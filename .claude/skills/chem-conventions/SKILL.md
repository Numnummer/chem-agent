# Запись веществ

| Вещество | SMILES | Почему так |
|---|---|---|
| Сера (элементарная) | `S1SSSSSSS1` | `S` — это H2S (неявные водороды) |
| Кислород | `O=O` | |
| Оксид этилена | `C1CO1` | |
| Оксид пропилена | `CC1CO1` | |
| NaOH | `[Na+].[OH-]` | ионная запись; в шаблонах реагирует `[OH-]`, `[Na+]` — противоион |
| Додеканол | `CCCCCCCCCCCCO` | |
| Электроэнергия | `resource` | не молекула; учитывается экономическим агентом |

- Противоионы (`[Na+]`, `[K+]`, `[Cl-]`, …) не считаются участниками при
  сравнении наборов веществ (`frag_set`).
- В реакции пишем только основной продукт; вода и соли — дело балансировщика.
  Заряженный продукт помечается `needs_counterion`.
- Формат реакции в выдаче: `реагенты>сопутствующий_реагент>продукт`.

# Термины

- **Шаблон** — превращение из корпуса (RDChiral, радиус 1 + спецгруппы), прямой
  и ретро-вариант.
- **Тип превращения (`type_key`)** — скелет шаблона без разметки и без уточнений
  по H и степени атомов. Разные шаблоны одного превращения имеют один тип.
- **Самопроверка** — шаблон воспроизводит свой прецедент.
- **Round-trip** — ретро-шаблон на продукте возвращает исходные реагенты.
- **Роль `reactant`** — атомы вещества входят в продукт; **`reagent`** — вещество
  только сопровождает (основание, окислитель).
- **internal / internal+intermediate** — все участники из набора пользователя /
  из набора и полученных из него промежуточных продуктов.
- **Курируемый шаблон (`trusted`)** — из ручной библиотеки; не режется по частоте.

# Термины текущего LLM-пайплайна команды (из презентации)

- **R1–R5** — проверки баланса атомов и зарядов; **chem_rules** — 22 правила
  запретов, дописываемые по найденным ошибкам.
- **Ярусы химического фильтра:** I — стоп-правила, II — канонические превращения,
  III — FG-сигнатуры (3162 из корпуса), IV — ручная проверка.
- **FG-сигнатура** — какие функциональные группы исчезли и какие появились.
  Концептуально близка к `type_key`.

# Метрики

- **Уникальность/разнообразие** — число разных `type_key`, а не reaction SMILES:
  реакции, отличающиеся длиной алкильного хвоста, — одно направление.
- **Новизна** — доля типов вне корпуса. Это отдельная исследовательская метрика,
  её не смешивают с покрытием.
- **Критерий ТЗ 2.1 (≥10 реакций)** считается по всему выбранному набору;
  маршруты до N стадий допускаются (решение команды до ответа заказчика, docs/decisions/0004).
- Любую метрику показываем рядом с бейзлайном и командой воспроизведения.
