Зачем: в прогоне full-v3/v4 сеть из перечня ТЗ даёт 11 типов превращений,
а ключевых промышленных реакций набора в патентном корпусе нет (ревью

Проверено для каждой реакции: SMILES разбираются в RDKit, атомы основного
продукта берутся из реагентов, RXNMapper размечает реакцию так, что шаблон
воспроизводит свой прецедент (13/13).

## Не вошло
- **S₈ + NaOH → Na₂S + Na₂S₂O₃** (диспропорционирование серы в щёлочи).
  В формате «одна молекула на реагент» не записывается: на три атома O
  тиосульфата нужно три OH⁻. Вносить готовым шаблоном — отдельная задача.
- **Электрохимия** (электролиз воды, хлор-щелочной процесс): электроэнергия —
  ресурс, шаблоны её не описывают; для хлор-щелочного процесса нужен NaCl,
  которого нет в перечне.

строке, `make fixtures`, `make test`, прогон и ревью.
