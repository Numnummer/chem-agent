# ТЗ: НИОКР «Мультиагентная система генерации идей и анализа для химической промышленности (прототип)»

## Общее описание

Программно-аппаратный комплекс с мультиагентной системой, которая
автоматически формирует и анализирует возможные химико-технологические
процессы. Анализ реакций и технологических маршрутов строится на
произвольно выбранном подмножестве исходных реагентов из перечня
приоритетных сырьевых компонентов:

**сера, кислород, окись пропилена, окись этилена, каустическая сода,
электрическая энергия, додециловый спирт.**

Можно выбрать не все компоненты, а только часть. После выбора система
определяет потенциальные химические взаимодействия между выбранными
веществами и оценивает условия их протекания, структуру продуктов,
использование энергии и ресурсную обеспеченность процесса.

## Use case: основной поток

1. **Ввод исходных компонентов** (на этапе настройки), например CO₂, Cl₂.
2. **Генерация реакций** химическим агентом по встроенным правилам химии и
   доступным данным; проверка корректности (массовый баланс, валентность).
3. **Сбор данных из внешних источников:** стоимость реагентов и доступные
   ресурсы (электричество, вода, воздух); нормализация в единый формат.
4. **Экономическая оценка:** ориентировочные затраты и прибыльность каждой
   реакции; точность не менее 85% относительно согласованных цен.
5. **Ранжирование** по экономической привлекательности, доступности ресурсов
   и другим критериям.
6. **Вывод:** список реакций с оценкой и **ссылками на исходные данные**.

## Что в ТЗ не определено (см. questions-for-customer.md)

- Целевые метрики агентов из п. 1.1.
- Метрика точности 85% и эталонный набор для её проверки.
- Считается ли критерий 2.1 на каждое вещество или на набор; допустимы ли
  многостадийные маршруты.
- Назначение векторной БД сверх хранения.
- Критерии и веса ранжирования («и другим критериям»).
