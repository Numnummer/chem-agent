# 0005. Роли «реагент» и «сопутствующий реагент»

**Статус:** принято

## Контекст
При нейтрализации и омылении атомы NaOH в основной продукт не переходят,
поэтому NaOH не попадает в шаблон и получает 0 реакций. При этом
одномолекулярный шаблон «кислота → карбоксилат» применялся к любой кислоте,
даже без щёлочи в наборе.

## Решение
- При извлечении реагенты делятся на реагирующие и сопутствующие; вторые
  сохраняются в прецедентах.
- Вещество получает роль `reagent` в шаблонах, где оно было сопутствующим.
- Одномолекулярный шаблон, у которого во всех прецедентах был сопутствующий
  реагент, применяется только если такой реагент есть в наборе.

## Последствия
Критерий «≥10 реакций на вещество» к NaOH неприменим: это реагент, а не
строительный блок. Ещё один аргумент считать критерий на набор (0004).

## Проверка
`test_naoh_participates_as_reagent`, `test_neutralization_requires_base_in_set`.
