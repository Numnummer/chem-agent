# 0012. Активация OH как уходящей группы

**Статус:** принято (28.09.2026). По ревью full-v3 (строки 14, 20).

## Контекст
Шаблон T01070 «диол → эпоксид» выдавал «пропиленгликоль + NaOH → оксид
пропилена». В прецедентах активация OH была (MsCl, Br₂, пиридин), но корпус
сохранил её лишь как сопутствующие вещества, а NaOH встречался во всех.
Гидроксил (и алкоксил) не уходит с sp³-углерода без кислоты или
активирующего реагента — так же построены дегидратация спиртов, эфиры из
двух спиртов, снятие защитных групп кислотой.

## Решение
- `intrinsic_functions`: если в шаблоне неразмеченный кислород уходит с
  sp³-углерода (одинарные связи, не ароматический), превращению нужна
  **активация**.
- Активацию закрывает вещество с функцией «кислота» или «активатор»
  (MsCl, TsCl, SOCl₂, PCl₃, POCl₃, PBr₃, PPh₃, азодикарбоксилаты,
  карбодиимиды) — `covers()`.
- Раскрытие эпоксида (кислород остаётся), SN2 галогенидов, этерификация
  кислот (уход OH с ацильного углерода) правило не затрагивают.

## Последствия
- На демо-корпусе ложная «этерификация» ПО + AcOH (0002) отсекается уже этим
  правилом; контроль обратной проверки перенесён на реальный шаблон T00277.
- Прецедент с активатором и основанием требует обоих; из перечня ТЗ
  активатора нет — такие шаблоны внутри набора не применяются.
