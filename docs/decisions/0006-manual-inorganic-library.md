# 0006. Ручная библиотека для неорганики и промышленных процессов

**Статус:** принято

## Контекст
В патентах USPTO почти нет реакций вроде S₈ + O₂ → SO₂, SO₂ → SO₃ или
щелочной абсорбции, а половина перечня ТЗ — неорганика.

## Решение
- `data/manual/inorganic.csv`: курируемые реакции с обязательным источником.
- Библиотека проходит тот же `map` → `extract`. RXNMapper справляется с
  неорганикой; проверено на 7 реакциях, самопроверка 100%.
- Файл передаётся в `--trusted`: такие шаблоны не режутся по `--min-count`,
  но самопроверку проходят.

## Последствия
- Электрохимию шаблоны не описывают (электроэнергия — ресурс). Для
  хлор-щелочного электролиза нужен отдельный механизм (roadmap R3).
- Если маппер ошибся на ручной реакции, её придётся вносить готовым
  шаблоном — это пока не поддерживается.

## Проверка
`test_manual_templates_are_trusted`; SLES-маршрут использует MAN-S01 и MAN-S02.
