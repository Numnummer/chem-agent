# 0015. Балансировщик уравнений

**Статус:** принято (29.09.2026). Roadmap R4.

## Контекст
Генератор выдаёт «реагенты > сопутствующий реагент > основной продукт» без
воды, солей и коэффициентов. Экономике (2.3) нужен расход сырья на тонну
продукта, критерию «валидная реакция» — баланс масс (шаг 2 основного потока ТЗ).

## Решение
`src/chem_agent/balancer.py`, команда `make balance IN=<network.csv|candidates.csv>`:
- вещество — вектор «атомы элементов + заряд»; коэффициенты — ядро матрицы
  (точные дроби); побочные продукты из пула (вода, соли, HX, CO₂, H₂, O₂, NH₃,
  N₂, MeOH, EtOH, ацетат, борная кислота, изобутилен, толуол, бензойная
  кислота, H₂S, ионы) — наименьший набор, дающий единственное решение с
  положительными коэффициентами; в перебор идут только вещества из элементов,
  которых не хватает в балансе;
- **стехиометрия шаблона:** коэффициенты органических реагентов и органических
  побочных продуктов равны коэффициенту продукта (одна молекула на слот, одна
  уходящая группа на продукт); неорганические (O₂, S₈, вода, NaOH) свободны.
  Без этого «сходятся» бессмыслицы (4 метилбензоата → 4 кислоты + изобутилен);
- анионы без противоиона (движок хранит HSO₃⁻) — натриевые соли;
- попытки по порядку: без реагента → с реагентом (расходуется) → NaOH как
  катализатор, реагирует вода → гидролиз (вода — ресурс, 0011) → без солевой
  записи; берётся первое «чистое» решение (без свободных ионов, без H₂ при
  окислителе-реагенте);
- статусы `ok`, `reagent_consumed`, `naoh_catalyst`, `hydrolysis`, `failed`
  (с остатком — что не удалось распределить); выделение H₂ помечается
  причиной «вероятно, не указан окислитель».

## Последствия
- full-v8: сеть до 4 стадий уравнена **полностью** (72% без расхода реагента,
  26% с расходом NaOH/O₂, 2% — OH⁻ как катализатор); открытый режим — ~95%.
  Отказы — уходящие группы вне пула (трифторацетил, тритил).
- Уравнение формальное: соли записываются натриевыми, выход 100%. Для
  экономики этого достаточно для расходных норм по стехиометрии; реальный
  выход — отдельный параметр.
