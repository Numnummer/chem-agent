# 0003. Разнообразие считается по типам превращений

**Статус:** принято

## Контекст
«Уникальность» в LLM-пайплайне считалась по reaction SMILES и относительно
обучающего корпуса. Две реакции, отличающиеся длиной алкильного хвоста, —
это одно направление переработки. А новизна относительно патентов
отбраковывает классическую промышленную химию, которая в патентах
представлена слабо.

Кроме того, одно превращение даёт несколько «разных» строк шаблона
(порядок атомов, степень конкретизации).

## Решение
- `type_key` — скелет шаблона без разметки и без уточнений по H и степени.
- **Покрытие** (продуктовая метрика) — число разных `type_key` на вещество
  и на набор.
- **Новизна** (исследовательская метрика) — доля типов вне корпуса. Считается
  отдельно и с покрытием не смешивается.
