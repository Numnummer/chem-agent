# 0002. Обязательная обратная проверка (round-trip)

**Статус:** принято

## Контекст
Шаблон радиуса 1 бывает слишком общим. Маппер разметил этерификацию так,
что уходит кислород спирта, и в шаблоне остался фрагмент `O–CH2–C`. Этот
фрагмент совпадает с кольцом эпоксида, и получается `ПО + AcOH →
пропилацетат` — химическая бессмыслица.

## Решение
К каждому продукту применяется ретро-шаблон. Кандидат принимается, только
если результат совпадает с исходными реагентами (без учёта противоионов).
`--no-roundtrip` оставлен только для сравнения.

## Последствия
На демо отклонены все 4 ложных кандидата и ни одного правильного. Стоимость —
один вызов rdchiral на кандидата.

## Проверка
`test_roundtrip_rejects_epoxide_deoxygenation`,
`test_roundtrip_off_lets_false_positive_through` (контроль, что проверка нужна).
