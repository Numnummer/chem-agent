# 0007. Уровни доверия реакций в выдаче

**Статус:** принято (сентябрь 2026); реализация — roadmap R11

## Контекст
Заказчик уточнил: нужны и реакции, которых нет в корпусе. Патенты и собранные
реакции — не все возможные реакции, реактивы под них экономический агент
ищет сам. Прежнее правило «реакция без `precedent_id` не выдаётся» это
исключало.

При этом реакции «вне корпуса» бывают двух разных видов. Шаблон, применённый
к новым веществам, даёт реакцию, которой в корпусе нет, но у её типа
превращения есть прецедент. Реакция совсем нового типа (гипотеза LLM)
прецедента не имеет вовсе: неизвестны ни выход, ни условия.

## Решение
Каждая реакция в выдаче получает уровень доверия `evidence_level`:

| Уровень | Что это | Обоснование |
|---|---|---|
| I | реакция есть в корпусе | `precedent_id` — сама реакция |
| II | аналог по шаблону: новые вещества, известный тип превращения | `precedent_id` — реакция того же шаблона |
| III | гипотеза: тип превращения вне корпуса (LLM, R8) | нет; явная пометка |

- Уровни I и II выдаются вместе; уровень виден в каждой строке.
- Уровень III выдаётся только отдельным списком с пометкой «гипотеза».
- Экономика для уровня III — стоимость сырья по стехиометрии и прибыльность
  как верхняя оценка при выходе 100%. В проверку точности 2.3 уровень III
  не входит: сравнивать не с чем.

## Последствия
- Правило в CLAUDE.md заменено: вместо запрета реакций без прецедента —
  обязательный уровень доверия.
- Сейчас движок выдаёт только II (и I, не отличая его от II). Нужно
  сравнение кандидата с корпусом по канонической записи — roadmap R11.
- Ранжирование (2.3) должно учитывать уровень, иначе гипотеза с выдуманным
  высоким выходом обгонит проверенный процесс.

## Проверка
Тест появится вместе с полем `evidence_level` (R11): кандидат, совпадающий с
прецедентом, получает I; аналог — II; у всех строк I–II есть `precedent_id`.
До этого действует `test_every_candidate_has_precedent`.
