# 0016. MVP: экономика, ранжирование, векторная БД, отчёт

**Статус:** принято (01.10.2026) решением команды до ответа заказчика
(questions-for-customer.md, вопросы 2–5, 8). Задача: показать готовый продукт
«набор веществ → отранжированные реакции с оценкой затрат», затем учесть
комментарии заказчика.

## Решение
**Команда.** `make analyze INPUTS=... TEMPLATES=...` (`chem_agent.pipeline`):
генерация внутри набора (+ вода и воздух) → уравнения (0015) → уровень
доверия I/II, прецедент, источник и условия прецедента из meta.csv
(`evidence.py`, 0007) → экономика → векторная БД → ранжирование → отчёт
(`results.json`, `results.csv`, `summary.md`, `report.html`).

**Экономика (2.3)** — `economics.py`, на 1 т основного продукта:
- расход сырья по уравнению / выход; выход **0,9 на стадию** (допущение);
- цена сырья — меньшая из рыночной и себестоимости маршрута в сети («купить
  или сделать»: SO₂ из серы дешевле рынка); промежуточные продукты
  считаются от исходного набора через всю цепочку;
- цена продукта — точная из прайса, иначе по классу (алкил(эфир)сульфаты,
  этоксилаты жирных спиртов, полигликоли — только C/H/O, эфиркарбоксилаты);
- кредит за побочные продукты с ценой — 50%; энергозатраты не оцениваются;
- **цены** — `data/prices/*.csv`: ориентировочная оценка команды (порядок
  величины мирового рынка, $/т), в отчёте помечено «заменить ценами заказчика».

**Точность (2.3)** — `economics_eval.py`, `make eval-economics`: эталон
`data/economics/reference.csv` — теоретические расходные нормы 11 продуктов
перечня по суммарному уравнению маршрута, посчитанные независимо (атомные
массы, без RDKit); точность = 1 − |прогноз − эталон| / эталон по затратам на
сырьё при тех же ценах и выходе 100%; бейзлайн — константный предиктор.
Это проверка всей расчётной цепочки (маршрут, стехиометрия, пересчёт через
промежуточные), а не точность против цен рынка: её даст эталон заказчика,
который заменит теоретические нормы в том же файле.

**Ранжирование** — веса в `data/config/mvp.json`: маржа 0,45 (доля маржи в
выручке), доказательность 0,25 (I — 1; II — по числу прецедентов шаблона и
наличию патента), маршрут 0,15 (1/стадия), качество уравнения 0,10
(H₂ без окислителя, OH⁻ вместо воды — штраф), только исходный набор 0,05.

**Векторная БД (2.2)** — `vectordb.py`: разностный отпечаток Моргана (заряд
учитывается: кислота ≠ анион) + структурный отпечаток + малый блок состава
(гомологи C12E2 ≠ C12E3); косинусная близость; хранение npz + jsonl. Поиск
похожих известных процессов — ручная библиотека и корпус (`--known`).

## Последствия
- Перечень ТЗ, 4 стадии (`outputs/2026-10-01-mvp/`, 45 с): 292 реакции,
  199 серий, **16 типов**; 292/292 уникальных вектора; полная экономика —
  153 реакции; точность на эталоне 100% (бейзлайн 32%).
- Все параметры, помеченные как допущения, — первые кандидаты на замену по
  комментариям заказчика: цены, выход, веса, метрика точности.
