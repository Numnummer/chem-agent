# 0001. Шаблоны из корпуса вместо свободной генерации реакций LLM

**Статус:** принято (сентябрь 2026)

## Контекст
ChemDFM-R-14B придумывает реагент и строит продукт сама. Валидность 42%,
разнообразие 3–4%, по этиленоксиду и пропиленоксиду — 5 и 1 реакция.
Химический фильтр (ярус III) пропускает только реакции, чья FG-сигнатура
уже есть в корпусе. То есть до пользователя доходят известные типы
превращений, применённые к субстрату, — а это ровно то, что делает шаблонный
движок, причём детерминированно.

## Решение
Основной генератор — шаблоны RDChiral, извлечённые из корпуса и применённые
к входным веществам. Продукт строится по разметке атомов, поэтому скелетный
баланс соблюдается всегда. У каждой реакции есть прецедент. LLM остаётся для
типов превращений вне корпуса (ярус IV).

## Последствия
- Порог 2.1 для эпоксидов закрывается детерминированно.
- Превращений, которых нет в корпусе, шаблоны не найдут никогда: для этого
  нужна LLM, а для неорганики — ручная библиотека (0006).
- Качество зависит от маппинга: единичные шаблоны отсекаются `--min-count`.
