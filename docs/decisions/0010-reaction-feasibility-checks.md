# 0010. Проверки осуществимости реакции при применении шаблона

**Статус:** принято (28.09.2026). Закрывает R15–R18 по ревью прогона full-v2
(docs/findings.md).

## Контекст
После решения 0009 в ревью full-v2 оставалось 30% ошибок, в многостадийной
сети — 38%. Причины:
- реагент без нужной функции, когда настоящий реагент прецедента не
  распознан (NaOH «окислял» и «протонировал», O₂ «восстанавливал»);
- хемоселективность: шаблон радиуса 1 не отличает OH кислоты от OH спирта,
  амидный N от аминного и не видит более сильного нуклеофила (SH, NH₂) в
  той же молекуле;
- ошибочные записи корпуса (кислород «переезжает» на соседний углерод);
- олигомеры: каждый аддукт ЭО/ПО считался отдельной реакцией.

Для измерения сделан стенд `make eval` (`chem_agent.review_eval`):
104 реакции из двух ревью с вердиктом химика
(`tests/regression/review_verdicts.csv`).

## Решение
1. **Функция по превращению (R15).** `intrinsic_functions`: по степеням
   окисления атомов центра (электроотрицательность по Полингу) шаблон
   окисляет, восстанавливает, протонирует или депротонирует. Если нужного
   реагента нет в самом шаблоне (окислитель — связь гетероатом–гетероатом,
   как O₂, SO₃, S₈; восстановитель — B, Al, Si, металл, H₂), он нужен как
   сопутствующий. Функция нужна и тогда, когда её использовали >50%
   прецедентов. Без такого реагента шаблон не применяется; в открытом
   режиме реагент берётся из прецедента, где он есть.
2. **Хемоселективность (R17).** При извлечении для атомов центра
   записывается класс в прецеденте (`atom_class`: спирт, фенол, кислота,
   амин, анилин, амид, тиол, (не)активированный арилгалогенид...) и самый
   сильный конкурирующий нуклеофил молекулы. При применении класс атома
   кандидата должен встречаться в прецедентах, а более сильного конкурента,
   чем в прецедентах, быть не должно.
3. **Миграция гетероатома (R16).** Шаблон, где в одной молекуле один углерод
   теряет связь с гетероатомом, а другой её получает (без изменения
   кратности связи между ними), отбрасывается при извлечении — 500 записей
   корпуса.
4. **Олигомеры (R18).** Шаблон не применяется к веществу, которое сам получил
   на прошлой стадии. Степень алкоксилирования — параметр процесса.

## Последствия
- Стенд: ошибочных в выдаче 20/35 → 0/35, верных сохранено 37/38.
  Стенд использовался при разработке, поэтому качество подтверждается
  независимым ревью на новых реакциях (findings, full-v3).
- Сеть внутри набора до 3 стадий: 304 → 39 реакций, 11 типов.
- Алкоксилирование выдаётся только с основанием (в 13 из 20 прецедентов
  было основание) — `test_alkoxylation_proposed_only_with_base`.
- Классификаторы функций и классов атомов — правила; вещество или атом с
  неизвестным классом проверку класса не проходит, если в прецедентах класс
  был известен.
