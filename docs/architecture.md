# Архитектура

## Контракт системы

**Вход**

```python
@dataclass
class AnalysisRequest:
    compounds: list[str]          # SMILES соединений пользователя (сейчас 5–6, дальше больше)
    roles: dict[str, str]         # отход / сырьё / нежелательный продукт — меняет знак в экономике
    available_amounts: dict       # т/год или кг/партия — без тоннажа нет экономики
    constraints: dict             # ограничения по T/P/оборудованию
    max_stages: int = 3           # глубина маршрутов
```

**Выход**

```python
@dataclass
class RankedReaction:
    reaction_smiles: str          # реагенты>сопутствующий_реагент>продукт
    type_key: str                 # тип превращения
    route: list[str]              # стадии, если маршрут многостадийный
    conditions: Conditions        # T, агенты, давление, количества (QUARC)
    economics: Economics          # затраты, выручка, маржа, чувствительность к ценам
    evidence: list[Source]        # прецеденты из корпуса (precedent_id)
    confidence: float
    rank_score: float
```

## Две скорости

| Слой | Что считает | Как часто меняется | Где живёт |
|---|---|---|---|
| Химический | реакции, маршруты, условия | почти никогда | предрасчёт офлайн → векторная БД |
| Экономический | цены, курс, доступность | ежедневно | на лету при запросе |

```
ОФЛАЙН (при изменении номенклатуры)
  соединения → шаблоны → round-trip → балансировщик → условия (QUARC) → векторная БД

ОНЛАЙН (запрос пользователя, секунды)
  запрос → выборка из БД → текущие цены (API + курс ЦБ) → экономика → ранжирование → выдача
```

Химию для фиксированного набора соединений можно посчитать один раз.
При расширении номенклатуры досчитывается только разница. Экономика не
кэшируется никогда.

## Инструмент под задачу

| Задача | Природа | Инструмент | Статус |
|---|---|---|---|
| Выбор партнёра | перебор конечного множества | пул набора → прецеденты → словарь покупаемых | `apply` |
| Построение продукта | применение правила | шаблон RDChiral + RDKit `RunReactants` | `apply` |
| Отсев ложных срабатываний | проверка обратимости | round-trip ретро-шаблоном | `apply` |
| Коэффициенты и побочные продукты | линейная алгебра | балансировщик (ядро матрицы атомов) | roadmap R4 |
| Запреты | логические правила | chem_rules команды | в LLM-пайплайне |
| Условия | статистическое предсказание | QUARC (агенты, T, количества) | отдельный модуль |
| Разнообразие и новизна | сравнение с корпусом | `type_key`, fingerprints | `extract` / R5 |
| Превращения вне корпуса | генерация гипотез | LLM (ChemDFM-R-14B), только ярус IV | roadmap R8 |

LLM не строит продукт и не считает баланс. Её зона — типы превращений,
которых нет в корпусе. В промпт ей передаются уже покрытые `type_key` как
исключения.

## Шаблонный движок (src/chem_agent/template_engine.py)

```
корпус ──map──► размеченный ──extract──► templates.jsonl ──apply──► кандидаты + отчёт
                                ▲
ручная библиотека (trusted) ────┘
```

- **map:** RXNMapper; агенты откладываются для QUARC.
- **extract:** один основной продукт; реагенты делятся на реагирующие и
  сопутствующие; RDChiral; самопроверка; `type_key`.
- **apply:** роли `reactant` и `reagent`; обязательный реагент для
  одномолекулярных шаблонов; round-trip; стадии (`--depth`); режим
  `--internal-only`.

## Векторная БД (ТЗ 2.2): зачем она на самом деле

1. Рабочий индекс дедупликации в контуре генерации: не тратить попытки на
   почти-дубликаты.
2. Поиск похожих известных процессов для новой реакции (evidence).
3. Кэш химического слоя для онлайн-контура.

Вектор — difference fingerprint реакции (RDKit), а не текстовый эмбеддинг:
он отражает структурное изменение, а не формулировку.
