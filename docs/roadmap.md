# Дорожная карта

Задачи идут по приоритету. У каждой есть критерий «готово, когда» — это
проверка, которую Claude запускает сам. Статус обновляется в этом файле.

Этап 2 заканчивается 01.12.2026. P0 — то, без чего не сдать этап 2.

### R4. Балансировщик
Полное уравнение с коэффициентами: побочные продукты (H₂O, соли,
противоионы) через ядро матрицы атомов (sympy nullspace) с пулом типовых
побочных продуктов. Нужен экономике (расход сырья на тонну продукта).
**Готово, когда:** у каждого кандидата из демо либо сбалансированное
уравнение, либо явная причина отказа; тесты на нейтрализацию, этоксилирование
и сульфатирование.
Статус: сделано (решение 0015, 29.09.2026): сеть full-v8 уравнена полностью,
открытый режим ~95%; `make balance IN=...`.

### R5. Векторная БД (ТЗ 2.2)

Статус: сделано (0016): numpy-хранилище вместо FAISS; 292/292 уникальных на перечне ТЗ.

### R6. Методика точности экономики (ТЗ 2.3)
Сначала договориться с заказчиком (см. questions-for-customer.md): эталонный

**Готово, когда:** скрипт оценки на эталонном наборе печатает метрику, и

Статус: MVP (0016): `make eval-economics`, эталон — теоретические нормы 11 продуктов;

### R12. Роль «сопутствующий реагент»
Вещество набора подставляется в среднюю часть по одному совпадению со
спектатором прецедента, без проверки функции: NaOH и S₈ «окисляют» и
«восстанавливают», ЭО/ПО становятся «вспомогательными» при конкурирующем
алкилировании. Варианты: роль `reagent` только если вещество было
сопутствующим в большинстве прецедентов шаблона и относится к классу
(основание, окислитель, восстановитель, акцептор кислоты); вещество, само
подходящее в слот шаблона, реагентом не считается.
**Готово, когда:** регрессионные тесты на строки 1, 7, 9, 16 из
`outputs/2026-09-27-full-v1/review_sample.csv` зелёные; повторное ревью.

### R13. Дубли по средней части
Одна реакция 3–4 раза с разными реагентами. Для критерия 2.1 и отчёта
считать реакцию по реагентам и продукту без средней части; варианты с
реагентом — атрибут, а не отдельная реакция.
**Готово, когда:** в отчёте «уникальных реакций» не зависит от числа
вариантов средней части; тест.

### R14. Слишком общие шаблоны
Почти все ошибочные шаблоны в ревью — с частотой 2 (T08459, T06056,
T06628, T03423, T03910). Проверить `--min-count 3–5`, радиус 2 или
спецгруппы RDChiral для редких шаблонов; мерить долю ошибок на той же
выборке.

### R15. Функция реагента по самому превращению — сделано (0010)
Если настоящий реагент прецедента не распознан (например, окисление по
Сверну — DMSO уходит в растворители), шаблону «ничего не нужно», и NaOH
проходит как реагент. Определять нужную функцию по изменению степени
окисления в шаблоне (потеря H₂ / присоединение O — окислитель; присоединение
H — восстановитель; протонирование — кислота), а не только по прецедентам.
**Готово, когда:** тесты на строки 15, 24, 31, 42 ревью full-v2.

### R16. Проверка скелета при извлечении — сделано (0010)
Отбрасывать шаблоны, где углеродный скелет вне реакционного центра
перестраивается или теряет атом C без окислителя/галогена (T01991, T02739,
T02560 — ошибочные записи корпуса).
**Готово, когда:** эти три шаблона не проходят extract; доля самопроверки
не упала заметно.

### R17. Слишком общие шаблоны и хемоселективность — сделано (0010), остаток в R19
T03618 («спирт + спирт → эфир») даёт 60% сети. Вариант: для шаблонов с
малым реакционным центром требовать больше разных прецедентов или
спецгруппы RDChiral; не применять шаблон, если в субстрате есть более
реакционный конкурирующий центр того же типа (SH против OH, алифатический
NH2 против ароматического, первичный OH против вторичного).

### R18. Алкоксилирование и олигомеры — сделано (0010, 0011)
Серия аддуктов ЭО/ПО (C12E1, C12E2, …) — одна реакция со степенью n, а не
отдельные реакции; ограничить наращивание олигомеров в сети. Валидность
маршрута — по всей цепочке, а не по последней стадии.

### R19. Открытый режим: металлирование и конкурирующие центры — сделано (0013), см. остаток в findings
По ревью full-v5 (26% ошибок в открытом режиме):
- C–H-алкилирование эпоксидом/электрофилом у неактивированного углерода
  требует металлирования (BuLi, LDA) — функция «сильное основание»;
- конкурирующие центры: NH гетероциклов, хлоргидрин (замкнётся в эпоксид),
  активированный арилгалогенид как электрофил-конкурент;
- региохимия из симметричного прецедента (T02083, Гевальд) — проверять
  прецедент без симметрии или несколько прецедентов;
- растворитель в реагентах (MeOH, n-PrOH при гидролизе нитрила).
**Готово, когда:** регрессия по строкам 36, 43, 55–61, 65 ревью full-v5;
повторное ревью открытого режима.
