# Выводы и результаты прогонов

Сюда дописываются итоги прогонов (скилл `/coverage-run`). Старые разделы не
переписываются, новые добавляются в конец.

## Разбор презентации текущего LLM-пайплайна (сентябрь 2026)

**Сильные стороны**
- Корпус: 114K сырых реакций → 92.6K после очистки (пакет `reaction_validation`).
- Четырёхъярусный химический фильтр; правила дописываются по найденным ошибкам (6 → 22).
- Честный слайд про метрики: 0.99 hamming, 0.96 micro-accuracy давления и
  0.46 MAE даёт константный предиктор.

**Проблемы**
- **Постановка расходится с ТЗ.** В пайплайне один SMILES на входе, а
  реагент модель придумывает сама. ТЗ требует взаимодействий внутри
  выбранного подмножества.
- **Хуже всего результаты по приоритетным веществам:** этиленоксид — 5
  уникальных реакций, пропиленоксид — 1. Это ниже порога 2.1. Цифра «30»
  у других веществ, по-видимому, упирается в лимит попыток.
- **Эффективность:** валидность 42%, из валидных различны 3–4%. Это порядка
  60–80 вызовов 14B-модели на одну уникальную реакцию (обратный расчёт).
- **Разнообразие считается по SMILES**, а не по типам превращений: реальное
  разнообразие, вероятно, ещё ниже.
- **Лицензия AGPL-3.0** у ChemDFM-R-14B: блокер к этапу 3 (сетевой доступ).
  Лицензионно чистый Qwen2.5-14B даёт 18.6% валидности против 42%.
- **Не показаны** векторная БД (2.2), методика точности экономики (2.3),
  критерии ранжирования.
- **Цены** берутся с Alibaba и Chem-Space, а ТЗ требует согласованных
  закупочных цен заказчика.
- **Подбор условий** (Parrot/QUARC) не входит ни в один измеряемый критерий ТЗ.
- На слайде статуса указан этап 1, хотя по срокам идёт этап 2.

**Открытые диагностики**
- Пересчитать 224 уникальные реакции LLM-пайплайна по `type_key` или FG-сигнатурам.
- Разложить 58% брака по причинам: какая доля чинится балансировщиком
  (забыты вода или противоион), а какая связана с химией (chem_rules).

## Демо шаблонного движка (синтетический корпус, 48 + 7 реакций)

Цифры показывают, как работает механизм, а не покрытие реального корпуса.

- Самопроверка пройдена у 100% шаблонов.
- Открытый режим, один шаг: по 21 реакции и 11–12 типов на каждый эпоксид.
  Round-trip отклонил 4 ложных кандидата («этерификация», раскрывающая
  эпоксид с выбросом O) и не задел правильных.
- Строго внутри набора за один шаг — **4 реакции на весь набор**. Порог 2.1
  за один шаг недостижим ни для какой модели.
- Внутри набора за 4 стадии — 114 реакций. Найден маршрут SLES:
  S₈ → SO₂ → SO₃; додеканол + ЭО; сульфатирование; нейтрализация NaOH.
- Рост сети по стадиям: 4 → 9 → 29 → 72. Без отсечения по оценке глубже
  2–3 стадий на реальном корпусе не пройти.
- Маппер ошибся на диэтиламин + ЭО (перепутал атомы ЭО и этила). Такие
  шаблоны единичны, их отсекает `--min-count 2`.

Корпус `outputs/2026-09-25-full-v1/corpus.csv` (88 987 реакций), результаты в
`outputs/2026-09-27-full-v1/`. CPU, 28 процессов: map 18 мин, extract 42 с,

- Шаблонов 15 670, с частотой ≥ 2 — 9 372, самопроверка 92%; в apply 8 046.
- Открытый режим: 431 832 реакции, но вещество набора входит в продукт лишь
  в **13 032 (3%)**, 515 типов. Остальное — «сопутствующий реагент» в чужой
  реакции, почти всё NaOH (409 тыс.). Эту цифру покрытием не считать.
- Внутри набора, стадия 1: 20 реакций, 8 типов. По вердикту chemistry-reviewer
  (`review_sample.csv`) корректных **разных** реакций **5** (7, если считать
  воду из водного NaOH): S₈ + O₂ → SO₂; додеканол + O₂ → додеканаль;
  → лаурат (NaOH); окси­этилирование и пропоксилирование додеканола.
  **Критерий 2.1 за одну стадию не выполнен**; бейзлайн — LLM-пайплайн:
  ЭО 5, ПО 1 уникальная реакция.
- Выборка из 50 реакций: OK 32%, сомнительно 30%, ошибка 38%.
- Системные дефекты: (1) роль «сопутствующий реагент» подставляет любое
  вещество набора без проверки функции — NaOH/S₈ как окислитель или
  восстановитель, ЭО/ПО как «вспомогательный» конкурирующий электрофил;
  (2) одна реакция 3–4 раза с разной средней частью — построчный счёт
  завышен ~в 3 раза; (3) шаблоны радиуса 1 с частотой 2 теряют контекст
  (SNAr без активации, региохимия); (4) [OH⁻] сопоставлен с водой.
- Задачи: R12–R14 в roadmap.
